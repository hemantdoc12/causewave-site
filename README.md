## How to Deploy / Test Locally

1. Clone the repo: `git clone https://github.com/hemantdoc12/causewave-site.git`
2. Open `index.html` in browser (or use Live Server extension)
3. For GitHub Pages:
   - Go to repo **Settings > Pages**
   - Source: **Deploy from a branch** → Branch: `main` → Folder: `/ (root)`
   - Save. Site will be live at `https://hemantdoc12.github.io/causewave-site/`
4. For custom domain (causewave.co.in):
   - In GitHub Pages settings, add custom domain
   - Create `CNAME` file in repo root with content: `causewave.co.in`
   - Update DNS at your registrar (A record to GitHub IPs or CNAME to hemantdoc12.github.io)
